# Fluxos passo a passo

## Visitante querendo conhecer a mentoria
1. Acesse `/` e leia o resumo da proposta.
2. Clique em **Mentoria** para conhecer método, etapas e entregáveis.
3. Acesse **Sobre** para conhecer a mentora.
4. Acesse **Contato** para iniciar uma conversa pelo link externo de WhatsApp.
5. A continuação comercial acontece fora deste repositório; não há gravação automática de lead confirmada no código.

## Equipe atualizando o conteúdo
1. Identifique a página em `app/` ou componente em `components/`.
2. Revise textos e mídias sem prometer funcionalidades não entregues.
3. Teste links internos e externos, incluindo navegação mobile.
4. Rode `npm run lint` e `npm run build`.
5. Atualize este conjunto de documentos e `docs/CHANGELOG.md`.
6. Faça commit do código e da documentação juntos.

## Acesso à área do aluno
O link atual aponta para `/login`. Como a rota não consta neste repositório, validar e corrigir o endereço de destino antes de considerar esse fluxo completo.
